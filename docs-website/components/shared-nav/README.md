# 两站界面的一致约定

【两站共享拷贝】公开站与 App 站各存一份本文件，内容逐字节相同，修改时两份一起改。

公开站（codedag.com）与 App 站（app.codedag.com）是同一个产品的两个站点，用户会在两站之间来回。两站的导航各按自己的用途设计，不要求相同：公开站的导航栏面向访客，App 站的顶栏与侧边栏面向已登录的用户。要一致的是下面五项：用户换站时认得出是同一个产品，同一个控件在两站是同一副样子、同一种用法。两站里相关的组件各有一句话指到这里。

1. **品牌：** 标识的图形与字标（图形 26px，字标 18px、中等字重，两者相隔 11px），主题紫，字体 Geist；页面底色（浅色、深色主题都取 `--color-fd-background` 的值）。
2. **顶栏：** 高 56px，吸在页面顶部；底色是页面底色的半透明（浅色 94%、深色 80%）加背景模糊；下边一条 1px 的分隔线，画在这 56px 之外（连线共 57px），颜色取 `--color-fd-border`。内容最宽 1440px，标识在最左，控件在最右，左右各留 16px。App 站控制台的侧边栏与公开站文档页的侧边栏同宽（268px）、同位置、同底色（`--color-fd-card` 的取值），右边线与顶栏的分隔线同色，所以从文档页进控制台，标识、顶栏和左栏都不动。窗口比 1440px 宽时，侧边栏的内容仍是靠右的 268px（与顶栏的标识左对齐），底色则一直铺到窗口的左边缘，左侧不露出页面底色。
3. **语言切换：** 以公开站导航栏上的为准。入口是 lucide 的 Languages 图标按钮（图标 20px）；下拉是一块圆角、半透明的面板，三种语言各占一行、各用本语言书写，当前语言的一行有底色。行为各站不同：公开站切换地址的语言前缀，App 站保存到 Cookie 与账号。
4. **主题：** 浅色、深色、跟随系统三种，默认跟随系统；图标依次是 lucide 的 Sun、Moon、Airplay，排成一枚胶囊形的三段开关，选中的一段有底色。公开站放在页脚，App 站放在头像菜单里。
5. **账号入口：** 头像的画法（`auth-area.tsx` 的 `AuthAvatar`），头像菜单悬停即展开的开合方式（`use-hover-menu.ts`），菜单开头的姓名与邮箱，菜单项的用词（`nav-translations.ts`）。菜单里有哪些项由各站决定：公开站的通向 App 站的页面，App 站的通向公开站的主页与文档。

改动其中任何一项时两站一起改，改完按改动的大小选合适的办法核对两站的实际效果，例如并排打开两站对照。本目录的文件逐字节相同，只保证第 5 项里共用的代码与用词不走样；其余各项靠两站各自的实现遵守本约定，文件相同不等于界面一致。
