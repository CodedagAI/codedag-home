本隐私政策说明 Zillion AI LLC（以下称“Zillion AI”或“我们”）在你使用 CodeDAG 时如何处理个人数据。CodeDAG 包括命令行工具（“CLI”）、网页控制台 app.codedag.com 和网站 codedag.com（统称“本服务”）。Zillion AI 作为这些数据的控制者，对其负责。本政策是我们[服务条款](/zh/terms)的组成部分。

## 概要 [#summary]

- CodeDAG 在你的电脑上运行。仓库里的代码、运行日志和 Agent 会话都留在你的电脑上。
- 你提交工作流时和工作流开始执行时，CLI 会把工作流文件连同其中的 prompt 发给我们，用来计算额度。我们算完即丢弃文件，只保留一段校验值。
- Claude Code 和 Codex 直接从你的电脑与各自的模型服务商通信，这些流量不经过我们。
- CLI 和网页控制台中没有使用分析。网站以匿名方式统计访问，不使用 Cookie。
- 我们不出售个人数据，也不将其用于广告。

## 我们收集的数据 [#what-we-collect]

### 账号信息 [#account]

你用 Google 账号登录。我们从 Google 获得你的姓名、邮箱地址、头像和 Google 账号 ID，连同 Google 签发的登录令牌一起保存在你的 CodeDAG 账号中，用来创建和识别你的账号，并显示当前登录的是谁。

你登录网页控制台时，我们会记录这次会话的 IP 地址和浏览器的 User-Agent。你在 CLI 中登录时，我们会签发令牌，让这台电脑保持登录；令牌连续 90 天未使用即失效。

### 付款信息 [#payment]

付款由 Stripe 处理。你在 Stripe 的结账页面上填写银行卡信息，这些信息直接交给 Stripe，我们从不接收或保存完整的卡号。为了在 Stripe 创建你的客户记录，我们会把你的 CodeDAG 账号 ID、姓名和邮箱地址发给 Stripe。

Stripe 会把结账、订阅和发票相关的事件记录发给我们，我们将其作为计费记录保存。其中包括你在 Stripe 的客户 ID 和订阅 ID、订阅方案、月付或年付、订阅状态、付款周期的起止日期和金额，还可能包括结账时填写的姓名、邮箱地址和账单信息。

### 用量与计费数据 [#usage]

CLI 在两个时刻连接我们的服务器：提交工作流时，检查额度是否足够；工作流即将开始执行时，扣除额度。每次请求包含：

- 工作流文件的完整内容（包括其中的 prompt 和写在里面的任何代码），以及它在仓库中的相对路径和文件格式；
- 本次要执行的任务 ID；
- CLI 版本、操作系统和处理器架构。

**丢弃的内容：** 我们读取工作流文件只是为了计算任务数和校验值，之后即丢弃文件的内容和路径，既不写入数据库，也不写入日志。

**保留的内容：** 每个开始执行的工作流，我们保留一条计费记录，内容包括你的账号 ID、被扣费的订阅、工作流文件的 SHA-256 校验值（无法由它还原出文件）、任务 ID、扣除的额度数、所属的额度周期、时间、CLI 版本、操作系统和处理器架构，以及防止同一次执行被重复扣费的技术标识。你的剩余额度和当前额度周期随订阅一起保存。提交时的额度检查不留下记录。

### Waitlist [#waitlist]

Waitlist 表单由 Tally 托管。表单要求填写邮箱地址，并可以选填你在用哪些编程 Agent、想用 CodeDAG 做什么；它还会记录你来自哪个语言的页面、通过哪个链接进入表单。你填写的内容保存在 Tally。我们只把你的邮箱地址用于内测邀请和上线通知。

### 服务器日志 [#logs]

我们的托管服务商会记录对 codedag.com 和 app.codedag.com 每次请求的基本信息，例如时间、请求的地址、响应状态，以及你的 IP 地址和 User-Agent（CLI 的 User-Agent 含有它的版本号）。我们的服务器还会记录错误。我们用这些日志来运行本服务、排查问题和防范滥用。我们不记录请求的内容，因此工作流文件不会出现在日志里。

### 邮件与反馈 [#communications]

你写信给我们时，我们会保存往来邮件，包括你的邮箱地址、邮件内容和附件，用于答复你和留存记录。你在我们的公开 GitHub 仓库中提交的 Issue 对所有人可见，适用 GitHub 的条款。

## 我们不收集的数据 [#not-collected]

- **仓库里的代码。** 我们不收集你仓库的源代码。唯一的例外是工作流文件：如上所述，它会随计费请求发送，包括其中的 prompt 和你写进去的任何代码。如果任务需要用到机密信息，可以把它放在本机的文件里，在 prompt 中写明让 Agent 读取哪个文件，这样上传的只有文件路径。
- **运行日志与 Agent 会话。** 任务日志、Agent 的会话内容和产出都留在你的电脑上。
- **产品使用分析。** CLI 和网页控制台中没有任何使用分析或遥测。CLI 只在登录、查询账号状态和处理额度时连接我们的服务器。
- **Agent 的通信。** Claude Code 和 Codex 直接从你的电脑把代码和上下文发给各自的模型服务商，适用这些服务商的条款。这些流量不经过 CodeDAG 的服务器。

## 网站访问统计 [#analytics]

codedag.com 使用 Vercel Web Analytics 了解网站的使用情况。它不使用 Cookie，也不在你的设备上保存任何标识。你浏览网站时，有关这次访问的信息按以下方式发送。

- **接收方：** Vercel Inc.，代表我们处理这些数据。
- **发送的信息：** 你浏览的页面地址（查询参数经过过滤）、来源页面、操作系统、浏览器和设备类型及其版本、根据 IP 地址推断的大致位置（国家、地区和城市），以及时间。你点击加入 Waitlist 的按钮，或某些通往文档和定价页的链接时，还会发送事件名称和该链接在页面上的位置（例如 `home-hero`），不含任何个人信息。
- **用途：** 汇总了解哪些页面被访问、哪些链接被使用，以便改进网站。
- **访客的统计方式：** Vercel 用请求生成的哈希值统计访客，这个哈希值每天重置，因此无法跨天或跨网站识别你。Vercel 表示，它记录的数据不与个人或 IP 地址相关联。我们不与任何其他方共享这些统计数据。

## Cookie 与本地存储 [#cookies]

codedag.com 不设置 Cookie。它会把浅色或深色主题等显示偏好保存在浏览器的本地存储中，这些数据留在你的设备上。app.codedag.com 只使用保持登录所必需的 Cookie。我们不使用任何广告或分析类 Cookie。Stripe 的结账页面与客户门户，以及 Tally 的表单，由这些服务商运营，它们可能按各自的政策使用自己的 Cookie。

## 我们如何使用数据 [#use]

我们使用个人数据来：

- 提供本服务：登录、账号、额度和订阅；
- 处理付款、防止重复扣费，并与 Stripe 核对计费记录；
- 答复你的邮件和请求，包括退款和数据请求；
- 向 Waitlist 中的用户发出内测邀请和上线通知；
- 保障本服务的安全，排查错误和滥用；
- 履行税务、会计等法律义务。

在法律要求说明处理依据的情况下：账号、用量和付款数据的处理是为了履行与你之间的合同；日志和网站统计基于我们运行和保护本服务、改进网站的正当利益；须依法保留的记录是为了履行法律义务；Waitlist 邮箱的处理基于你的同意，你可以随时撤回。

我们不出售个人数据，不将其共享用于广告，也不用你的工作流文件、prompt 或代码训练 AI 模型。

## 服务提供方 [#providers]

我们只与帮助我们运行本服务的服务提供方共享个人数据，并且只提供各自所需的部分：

| 服务提供方 | 为我们做什么 |
|---|---|
| Vercel | 托管 codedag.com 和 app.codedag.com；网站访问统计；服务器日志 |
| 托管数据库服务商 | 托管保存账号、订阅和计费记录的数据库 |
| Google | Google 账号登录 |
| Stripe | 付款、订阅和发票 |
| Tally | Waitlist 表单 |
| 企业邮箱服务商 | 托管我们的邮箱 |

各服务提供方按其自己的条款和隐私政策处理数据。在法律有此要求时，或为了保护用户或本服务的权利与安全，我们也可能披露个人数据。如果 Zillion AI 发生合并、收购或资产出售，个人数据可能随交易一并转移，并继续适用本政策。

## 跨境传输 [#transfers]

Zillion AI 位于美国，我们的服务提供方在美国以及其开展业务的其他国家处理数据。你使用本服务时，你的数据会被传输到这些国家并在那里处理，这些国家的数据保护规则可能与你所在地不同。

## 数据保留期限 [#retention]

- **账号、订阅和计费记录：** 在你的账号存续期间保留。账号删除后，计费记录只在会计、税务或其他法律义务要求的期限内保留。
- **工作流文件的内容和路径：** 不保留，额度算完即丢弃。
- **服务器日志：** 最多保留 30 天，之后删除。为调查某一安全事件或滥用行为，或为履行法律义务，相关部分可以保留更久。
- **网站访问统计：** 只以匿名统计数据的形式保存，每天的访客哈希值会被丢弃。
- **Waitlist 记录：** 保留到内测邀请和上线通知不再需要时，或你要求删除时为止。
- **邮件：** 在处理你的请求并留存记录所需的期间内保留。

## 你的权利 [#rights]

你可以要求我们：

- 提供我们持有的你的个人数据的副本，包括以可移植的格式提供；
- 更正不准确的数据；
- 删除你的账号和个人数据，或把你从 Waitlist 中移除；
- 限制或反对某些处理，或撤回你给予的同意。

根据你所在的地区，例如欧洲经济区、英国、加利福尼亚州或日本，你可能依法享有这些权利。请从你的 CodeDAG 账号所用的邮箱地址写信到 <Email user="privacy" /> 提出请求，以便我们确认账号属于你。这些请求通过邮件处理，网页控制台目前没有相应的自助功能。如果你要删除账号，而订阅仍然有效，请先取消订阅，以免续费。依法须保留的计费记录按上文所述保留。

我们不会因为你行使这些权利而区别对待你。你也可以向所在地的数据保护机构投诉。

## 安全 [#security]

与我们服务器之间的连接经 HTTPS 加密，我们也只保存本政策所述的数据。任何传输或存储方式都无法做到绝对安全。如果发生影响你个人数据的泄露事件，我们会按法律要求通知你。

## 儿童 [#children]

本服务面向年满 18 周岁的人（见[服务条款](/zh/terms#accounts)）。我们不会在知情的情况下收集儿童的个人数据。如果你认为有儿童向我们提供了个人数据，请写信告诉我们，我们会将其删除。

我们可能更新本政策。新版本会发布在本页，并更新生效日期。变更对我们处理你数据的方式有实质影响的，我们还会在变更生效前通过邮件或在网页控制台中告知你。
