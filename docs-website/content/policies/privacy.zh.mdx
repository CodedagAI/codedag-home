本隐私政策说明 Zillion AI LLC（以下称“Zillion AI”或“我们”）在你使用 CodeDAG 时如何收集、使用和共享个人数据。CodeDAG 包括命令行工具（“CLI”）、网页控制台 app.codedag.com 和网站 codedag.com（统称“本服务”）。Zillion AI 是这些数据的控制者。本政策是我们[服务条款](/zh/terms)的组成部分。

CodeDAG 在你的电脑上运行，你的代码、运行日志和 Agent 会话都留在那里。我们只收集运行你的账号、计算额度和处理付款所需的数据。

## 我们收集的数据 [#what-we-collect]

### 你提供的数据 [#you-provide]

- **账号信息。** 你用 Google 账号登录，我们会获得你的姓名、邮箱地址、头像和 Google 账号 ID。在 CodeDAG 只对受邀用户开放期间，只有邀请名单上的邮箱地址才能创建账号。邀请名单来自 Waitlist 和我们单独发出的邀请。
- **付款信息。** 在付款页上，我们按你之前的选择或 IP 地址的大致位置预先填好账单地区，例如所在的国家，税务规则有要求时还有邮政编码，你可以修改。该地区可以付费时，我们会把账单地区发给 Stripe 计算税费，即使你最后没有订阅。你在我们的付款服务商 Stripe 的付款表单中填写银行卡信息，我们从不接收完整的卡号。订阅时，我们记录你同意续费条款的时间、当时看到的条款文字和价格。
- **Waitlist。** 你加入 Waitlist 时，我们的表单服务商会收集你的邮箱地址、你对几个选填问题的回答，以及你是从哪个页面来到表单的。
- **往来邮件。** 你写信给我们时，我们会保存你的来信、邮箱地址和附件。你在我们的公开 GitHub 仓库中提交的 issue 对所有人可见，按 GitHub 的条款处理。

### 你使用本服务时收集的数据 [#usage]

- **工作流文件。** 为了计算和扣除额度，CLI 会把你运行的工作流文件发给我们，包括其中的 prompt 和写在里面的任何代码，同时发送要运行的任务，以及 CLI 版本、操作系统等技术信息。我们只用这个文件计算额度和生成校验值，随后丢弃文件内容，不写入我们的数据库，也不写入日志。CLI 具体发送哪些内容、在什么时候发送，见[你的数据边界](/zh/docs/account/login-and-account#data-boundary)。
- **用量与额度记录。** 每个开始执行的工作流，我们都会保留一条记录，例如时间、任务、扣除的额度，以及工作流文件的校验值；从校验值无法还原文件。我们还保存你的额度余额，以及我们对额度做的调整，例如按[退款政策](/zh/refund#credits)退回额度。
- **设备与日志信息。** 我们的服务器和服务提供方会记录访问本服务的请求的技术信息，例如你的 IP 地址、浏览器或 CLI 版本、操作系统、请求时间，以及出现的错误。
- **网站访问统计。** codedag.com 使用一项不依赖 Cookie 的访问统计服务，汇总统计访问情况。它会记录你浏览的页面、来源页面、浏览器和设备类型、大致位置，以及你点击的链接等信息，但无法跨天或跨网站识别你。

你仓库里的代码、运行日志和 Agent 会话都不会发给我们。Claude Code、Codex 等编码 Agent 直接从你的电脑把代码和上下文发给各自的模型服务商，按这些服务商的条款处理，这些流量不经过我们。CLI 和网页控制台中没有产品使用分析。

### 来自第三方的数据 [#third-parties]

Stripe 会把你的订阅和付款记录发给我们，例如方案、计费日期和金额、账单地址，以及银行卡的发卡国家。我们结账页上 Stripe 的付款软件还可能收集你的设备信息和你在该页面上的操作，用于防范欺诈。Stripe 按其[隐私政策](https://stripe.com/privacy)处理这些信息。

## 我们如何使用数据 [#use]

我们使用个人数据来：

- 提供本服务，包括登录、账号、额度和订阅；在 CodeDAG 只对受邀用户开放期间，决定谁可以创建账号，以及账号获得哪种免费额度；
- 处理付款、计算税费、确认你所在的地区能否使用付费方案，防范欺诈和重复扣费；
- 向你发送与账号、额度和订阅有关的消息，答复你的请求；
- 向 Waitlist 中的用户发出内测邀请和上线通知，了解大家想怎样使用 CodeDAG；
- 保障本服务的安全，排查错误和滥用；
- 汇总了解网站的使用情况，以便改进网站；
- 履行税务、会计、消费者保护等法律义务。

我们不出售个人数据，不将其共享用于广告，也不用你的工作流文件、prompt 或代码训练 AI 模型。

## 处理依据 [#legal-bases]

我们基于以下依据处理个人数据：

- **合同：** 提供你注册使用的本服务，包括账号、额度和付款。
- **正当利益：** 保障本服务的安全并排查问题、防范欺诈、在内测期间限制注册，以及改进网站。
- **同意：** 你加入 Waitlist 后，给你发送内测和上线的邮件。你可以随时撤回同意。
- **法律义务：** 保留税务、会计和消费者保护法律要求的记录。

## 我们如何共享数据 [#sharing]

我们只在以下情况下共享个人数据：

- **服务提供方。** 我们借助一些公司来运行本服务，涉及托管与数据库、登录、付款处理与税费计算、错误追踪、日志与可用性监控、网站访问统计、表单、邮件，以及代码托管与自动化等方面。每家只获得完成各自任务所需的数据。其中一些服务提供方，例如我们的付款服务商，也会按其自己的隐私政策处理数据。
- **法律要求与安全。** 在法律有此要求时，或为了保护用户或本服务的权利与安全，我们可能披露个人数据。
- **业务转让。** 如果 Zillion AI 发生合并、收购或资产出售，个人数据可能随交易一并转移，并继续适用本政策。

## Cookie 及类似技术 [#cookies]

codedag.com 不使用 Cookie。它会把浅色或深色主题等显示偏好保存在浏览器的本地存储中，这些数据留在你的设备上。app.codedag.com 只使用运行所必需的 Cookie，例如保持登录、记住所选语言的 Cookie。我们不使用广告类 Cookie。付款表单、账单门户和 Waitlist 表单由我们的付款服务商和表单服务商运营，它们可能使用自己的 Cookie。

我们不会跨网站追踪你，因此不会对“请勿追踪”（Do Not Track）信号作出不同的响应。除了本政策所述的访问统计和服务提供方，我们不允许第三方在我们的网站上收集你的活动信息。

## 跨境传输 [#transfers]

Zillion AI 位于美国，我们的服务提供方在美国以及其开展业务的其他国家处理数据。我们的团队也可能从其他国家访问数据。法律要求为这类传输采取保障措施时，我们依靠服务提供方的合同承诺，使数据得到相当水平的保护，例如对来自欧洲经济区或英国的数据，采用欧盟委员会批准的标准合同条款及英国的对应文本。如需副本，请联系我们。

## 数据保留期限 [#retention]

我们只在实现本政策所述目的所需的期间内保留个人数据，之后将其删除或匿名化：

- **账号、额度、订阅与计费记录：** 在你的账号存续期间保留。账号删除后，订阅与计费记录只在税务、会计或其他法律义务要求的期限内保留。
- **工作流文件的内容：** 不保留，额度算完即丢弃。
- **日志与错误报告：** 只短期保留，以满足运行、排查和保护本服务的需要。为调查某一安全事件或滥用行为，或为履行法律义务，相关记录可以保留更久。
- **Waitlist 与邀请名单记录：** 保留到发送邀请和上线通知都不再需要时，或你要求删除时为止。
- **邮件：** 在处理你的请求并留存记录所需的期间内保留。

## 你的权利 [#rights]

根据你所在的地区，例如欧洲经济区、英国、加利福尼亚州或日本，你可能有权：

- **访问**我们持有的你的个人数据，并以可移植的格式获取副本；
- **更正**不准确的数据；
- **删除**你的账号和个人数据，或把你从 Waitlist 中移除；
- **反对或限制**某些处理；
- **撤回**你给予的同意。

提出请求时，请从你的 CodeDAG 账号所用的邮箱地址写信到 <Email user="privacy" />，以便我们确认账号属于你。如果你要删除账号，而订阅仍然有效，请先取消订阅，以免续费。我们不会因为你行使这些权利而区别对待你。对我们处理数据的方式有疑虑或投诉，也请写信到同一地址。我们会在 20 个工作日内答复请求和投诉。如果你对答复不满意，还可以向所在地的数据保护机构投诉。

## 安全 [#security]

我们只保存本政策所述的数据，与我们服务器之间的连接经 HTTPS 加密，并限制能够访问个人数据的人员。任何传输或存储方式都无法做到绝对安全。如果发生影响你个人数据的泄露事件，我们会按法律要求通知你。

## 儿童 [#children]

本服务面向年满 18 周岁的人（见[服务条款](/zh/terms#accounts)）。我们不会在知情的情况下收集儿童的个人数据。如果你认为有儿童向我们提供了个人数据，请写信告诉我们，我们会将其删除。

## 本政策的变更 [#changes]

我们可能更新本政策。新版本会发布在本页，并更新生效日期。变更对我们处理你数据的方式有实质影响的，我们还会在变更生效前通过邮件或在网页控制台中告知你。
