## 本サービス [#service]

CodeDAG は、開発タスクで構成されるワークフローを、お客様のコンピューター上で実行します。各タスクは、Claude Code や Codex など、お客様ご自身がインストールしてログインしたサードパーティのコーディングエージェントが実行し、実行結果はお客様のローカルリポジトリに残ります。

本サービスには、AI モデルの利用権は含まれません。コーディングエージェントの利用料は、各提供元が別途請求します。

## クレジット [#credits]

ワークフローを実行すると CodeDAG クレジットを消費します。消費の仕組みは[クレジットとサブスクリプション](/ja/docs/account/credits-and-subscription)をご覧ください。クレジットは、サブスクリプションによって、または登録時やベータ版への招待時などに当社が無料で付与する無料クレジットとして得られます。

- **利用範囲：** クレジットは、付与されたアカウントでのみ使用できます。クレジットに現金価値はなく、換金することも、譲渡することもできません。使用済みのクレジットは、[返金ポリシー](/ja/refund#credits)に定める場合を除き、戻りません。
- **有効期間：** サブスクリプションのクレジットのうち使い切らなかった分は、次のクレジット期間に繰り越されません。無料クレジットの有効期間は、お客様のアカウントに表示されるとおりです。すでにお持ちの無料クレジットに終了日を設定する場合（ベータ版の終了時など）は、事前にお知らせします。
- **無料クレジット：** 支払いカードの登録は不要で、有料サブスクリプションに切り替わることはなく、終了時に課金されることもありません。当社は、無料クレジットの付与を変更または終了することがあります。

## サブスクリプションと支払い [#subscription]

サブスクリプションが有効な間、お客様は[料金ページ](/ja/pricing)に記載の数とクレジット期間でクレジットを得られます。

- **料金：** お客様は、決済ページに表示される料金を、そこに表示される通貨でお支払いいただきます。料金が税込みかどうかも決済ページに表示されます。
- **請求：** 支払いは Stripe が処理します。サブスクリプションは前払いで請求され、解約するまで各請求期間の終了時に自動更新されます。
- **有料プランを利用できる地域：** 有料サブスクリプションは、すべての国と地域で利用できるわけではありません。決済ページでお客様の請求先地域をお聞きし、その地域からサブスクリプションに登録できるかをお知らせします。
- **税金：** 当社が税金を徴収する義務を負う地域では、請求先地域をもとに税金を計算し、お支払いの前に表示します。故意に誤った請求先地域を指定した場合、それによって生じる税金はお客様の負担となります。当社が税金を徴収しない地域では、ご購入に適用される税金はお客様が負担するものとします。
- **支払いの失敗：** 更新時の支払いに失敗した場合、支払いが完了するまでサブスクリプションは利用できません。お支払いを回収できない場合、サブスクリプションが終了することがあります。
- **値上げ：** サブスクリプションの料金を値上げする場合は、新しい料金での最初の更新の 30 日前にメールでお知らせします。同意いただけない場合は、その更新までに解約できます。

## 解約と返金 [#cancellation]

サブスクリプションは、Web コンソールの請求ページからいつでも解約できます。解約は現在の請求期間の終了時に有効となります。ただし、お客様に適用される法令がより早い終了を認めている場合は、それに従います（[返金ポリシー](/ja/refund#when-we-refund)をご覧ください）。それまではサブスクリプションが有効なままで、クレジットも通常どおり使え、解約を取り消すこともできます。サブスクリプションの終了後に課金されることはありません。返金（14 日間の返金を含みます）は、[返金ポリシー](/ja/refund)に従って取り扱います。
