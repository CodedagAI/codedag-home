本服务条款（“本条款”）是你与 Zillion AI LLC（一家依美国怀俄明州法律设立的有限责任公司，以下称“Zillion AI”或“我们”）之间的协议，适用于你对 CodeDAG 的使用，包括命令行工具（“CLI”）、网页控制台 app.codedag.com、网站 codedag.com 和文档（统称“本服务”）。你创建账号或使用本服务，即表示同意本条款。我们的[隐私政策](/zh/privacy)和[退款政策](/zh/refund)是本条款的组成部分。

## 本服务 [#service]

CodeDAG 在你的电脑上执行由开发任务组成的工作流。每个任务由你自行安装并登录的第三方编程 Agent 完成，例如 Claude Code 或 Codex，结果都留在你本地的仓库里。

本服务不包含任何 AI 模型的使用权，你使用编程 Agent 的费用由其服务商另行收取。

## 额度 [#credits]

执行工作流会消耗 CodeDAG 额度，怎样消耗见[额度与订阅](/zh/docs/account/credits-and-subscription)。额度来自订阅，或者我们无偿提供的免费额度，例如在你注册或受邀参加测试时。

- **使用范围：** 额度只能在获得它的账号上使用，没有现金价值，不能兑换成现金，也不能转让。已经使用的额度不会退回，[退款政策](/zh/refund#credits)中规定的情形除外。
- **有效期：** 订阅额度当期没用完的，不累计到下一期。免费额度的有效期以你账号中显示的为准；如果我们为你已有的免费额度设定结束日期，例如在测试结束时，会提前告知你。
- **免费额度：** 无需绑定支付卡，不会转为付费订阅，结束时也不会产生任何扣款。我们可能变更或取消免费额度的发放。

## 订阅与付款 [#subscription]

订阅有效期间，你按[定价页](/zh/pricing)上列出的数量和周期获得额度。

- **价格：** 你按付款页上显示的价格和币种付款，付款页也会写明价格是否含税。
- **计费：** 付款由 Stripe 处理。订阅预先收费，在每个付款周期结束时自动续费，直到你取消。
- **付费地区：** 不是所有国家和地区都能使用付费订阅。付款页会询问你的账单地区，并告诉你能否从该地区订阅。
- **税费：** 在我们须代收税费的地区，我们按你的账单地区计算税费，并在付款前显示。如果你故意提供不正确的账单地区，由此产生的任何税费由你承担。在我们不代收税费的地区，适用于你这次购买的税费由你自行承担。
- **扣款失败：** 续费扣款失败时，订阅在付款成功之前不可用。款项无法收取的，订阅可能结束。
- **涨价：** 如果我们提高你的订阅价格，会在你按新价格的第一次续费之前 30 天发邮件通知你。你不同意的，可以在这次续费之前取消订阅。

## 取消与退款 [#cancellation]

你可以随时在网页控制台的账单页取消订阅。取消在当前付款周期结束时生效，除非适用于你的法律允许你更早结束订阅（见[退款政策](/zh/refund#when-we-refund)）。在此之前，订阅仍然有效，额度照常可用，你也可以撤销取消。订阅结束后不会再扣款。退款按[退款政策](/zh/refund)办理，包括 14 天退款。
