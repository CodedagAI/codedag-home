本服务条款（“本条款”）是你与 Zillion AI LLC（一家依美国怀俄明州法律设立的有限责任公司，以下称“Zillion AI”或“我们”）之间的协议，适用于你对 CodeDAG 的使用，包括命令行工具（“CLI”）、网页控制台 app.codedag.com、网站 codedag.com 和文档（统称“本服务”）。你创建账号或使用本服务，即表示同意本条款。我们的[隐私政策](/zh/privacy)和[退款政策](/zh/refund)是本条款的组成部分。

## 本服务 [#service]

CodeDAG 在你的电脑上执行由开发任务组成的工作流。每个任务由你自行安装并登录的 Claude Code 或 Codex 完成，分支、合并和结果都留在你本地的仓库里。我们的服务器负责登录、账号、订阅，以及额度的计算和扣除。

本服务不包含任何 AI 模型的使用权。你需要有自己的 Claude Code 或 Codex 账号，它们的用量由各自的服务商按其条款收费。

## 测试阶段 [#beta]

CodeDAG 目前处于测试阶段。测试期间（包括仅凭邀请使用的阶段），功能、限制和本服务的工作方式都可能变化，本服务也可能中断、受限或停止提供。重大变化我们会尽量提前在文档中或通过邮件告知。测试期间本服务按现状提供，具体见[免责声明](#disclaimers)。

## 资格与账号 [#accounts]

你须年满 18 周岁；如果你所在地的成年年龄更高，须达到该年龄。代表某个组织使用本服务的，你确认自己有权代表该组织接受本条款。

你用 Google 账号登录，第一次登录时 CodeDAG 账号随之创建。请妥善保管登录凭证，你的账号下发生的活动由你负责。如果你认为有人在使用你的账号，请尽快告诉我们（见[联系方式](#contact)）。

## 额度 [#credits]

执行工作流会消耗 CodeDAG 额度。只有用 `cdg dag submit` 提交的工作流计费：工作流中每个任务 1 点，在工作流开始执行时扣除。提交工作流和排队都不扣，开始执行之前被取消的工作流也不产生费用。工作流开始执行之后，无论其中的任务结果如何，已扣除的额度都不会自动退回，例外情形见[退款政策](/zh/refund)。

额度没有现金价值，不能兑换成现金，也不能在账号之间转让。

## 免费额度 [#free-credits]

新账号获赠 800 点免费额度，每个账号一次，自注册起 30 天内有效，无需绑定支付卡。使用免费额度与订阅能用的功能相同。免费额度用完或到期后，需要订阅才能继续提交工作流。由于不涉及支付卡，免费额度不会自动转为付费订阅，到期时也不会产生任何扣款。在免费额度尚有剩余时订阅的，剩余额度并入第一个付费周期。

我们可能变更或取消面向今后新注册账号的免费额度。此类变更不影响已经发放的额度。

## 订阅与付款 [#subscription]

CodeDAG 只有一个订阅方案，所有用户的功能相同。

- **价格：** 月付每月 \$12，或年付每年 \$96，折合每月 \$8，比月付省 33%。
- **额度：** 每月 800 点，在每个月度额度周期开始时重置，当月没用完的不累计。年付同样按月发放额度，不是一次发放全年的额度。
- **第三方费用：** 订阅不包含第三方 AI 模型的费用。
- **计费：** 付款由 Stripe 处理。订阅预先收费，在每个付款周期结束时自动续费，直到你取消。适用的税费以结账页为准。
- **额度用完：** 当月额度用完后，可以等待下一个月度额度周期，或另外注册一个账号。新账号有自己的额度和订阅，不与原账号合并。目前不提供额度补充包。
- **扣款失败：** 续费扣款失败时，订阅在付款成功之前不可用。
- **价格调整：** 如果我们调整价格，会在新价格适用于你的下一次续费之前至少 30 天通知你。你不同意的，可以在此之前取消订阅。

## 取消与退款 [#cancellation]

你可以随时在网页控制台的 Billing 页取消订阅。取消在当前付款周期结束时生效：在此之前订阅仍然有效，额度照常可用，之后不会再扣款。

已付费用原则上不退款，例外只有重复扣费、计费故障和法律要求退款的情形。取消与退款的规则以及申请退款的方式，见[退款政策](/zh/refund)。

## 你的内容 [#your-content]

你的代码、工作流文件和 prompt，以及你的 Agent 产出的内容（“你的内容”），所有权利都归你所有，我们不主张其中任何部分的所有权。

你的代码、运行日志和 Agent 会话都留在你的电脑上。为了计算和扣除额度，CLI 会在你提交工作流时和工作流开始执行时，把这个工作流文件连同其中的 prompt 发给我们。我们计算完即丢弃文件内容，只保留一段校验值，详见[隐私政策](/zh/privacy#usage)。你授权我们仅在提供本服务所需的范围内处理这些数据。请不要把密码、密钥等机密信息写进工作流文件，而是放在本机的文件里。
