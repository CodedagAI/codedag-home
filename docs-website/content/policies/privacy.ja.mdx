本プライバシーポリシーは、お客様が CodeDAG を利用する際に、Zillion AI LLC（以下「Zillion AI」または「当社」）が個人データをどのように取り扱うかを説明するものです。CodeDAG には、コマンドラインツール（以下「CLI」）、Web コンソール app.codedag.com、Web サイト codedag.com（以下総称して「本サービス」）が含まれます。これらのデータの管理者として責任を負うのは Zillion AI です。本ポリシーは、当社の[利用規約](/ja/terms)の一部を構成します。

## 概要 [#summary]

- CodeDAG はお客様のコンピューター上で動作します。リポジトリ内のコード、実行ログ、エージェントのセッションは、そのコンピューターに残ります。
- ワークフローの投入時と実行開始時に、CLI はクレジットを計算するため、プロンプトを含むワークフローファイルを当社に送信します。当社は計算後にファイルを破棄し、チェックサムだけを保持します。
- Claude Code と Codex は、お客様のコンピューターから直接、各モデル提供元と通信します。この通信は当社を経由しません。
- CLI と Web コンソールには、利用状況の分析機能はありません。Web サイトのアクセスは、Cookie を使わずに匿名で集計しています。
- 当社は個人データを販売せず、広告にも利用しません。

## 収集するデータ [#what-we-collect]

### アカウント情報 [#account]

ログインには Google アカウントを使います。当社は Google から、お客様の氏名、メールアドレス、プロフィール画像、Google アカウント ID を受け取り、Google が発行するログイン用のトークンとともに CodeDAG アカウントに保存します。これらは、アカウントの作成と識別、およびログイン中のユーザーの表示に使います。

Web コンソールにログインすると、そのセッションの IP アドレスとブラウザのユーザーエージェントを記録します。CLI でログインすると、そのコンピューターのログイン状態を保つためのトークンを発行します。このトークンは、90 日間使われないと失効します。

### 支払い情報 [#payment]

支払いは Stripe が取り扱います。カード情報は Stripe の決済ページで入力され、Stripe に直接送られます。当社がカード番号の全桁を受け取ったり保存したりすることはありません。Stripe に顧客情報を作成するため、当社は CodeDAG のアカウント ID、氏名、メールアドレスを Stripe に送信します。

Stripe からは、決済、サブスクリプション、請求書に関するイベントの記録が当社に送られ、当社はそれを課金記録として保存します。これには、Stripe の顧客 ID とサブスクリプション ID、プラン、支払いサイクル、サブスクリプションの状態、請求期間の日付と金額が含まれ、決済時に入力された氏名、メールアドレス、請求先情報が含まれることもあります。

### 利用量と課金のデータ [#usage]

CLI が当社のサーバーに接続するのは、2 つのタイミングです。ワークフローの投入時にはクレジットが足りるかを確認し、実行開始の直前にはクレジットを差し引きます。各リクエストには、次の情報が含まれます。

- ワークフローファイルの内容全体（プロンプトや、ファイル内に書かれたコードを含みます）、リポジトリ内での相対パス、ファイル形式
- 今回実行するタスクの ID
- CLI のバージョン、OS、プロセッサーアーキテクチャ

**破棄するもの：** ワークフローファイルを読み取るのは、タスク数を数えてチェックサムを計算するためだけです。その後、ファイルの内容とパスは破棄し、データベースにもログにも書き込みません。

**保持するもの：** 実行を開始したワークフローごとに、課金記録を 1 件保持します。内容は、お客様のアカウント ID、課金したサブスクリプション、ワークフローファイルの SHA-256 チェックサム（ここからファイルを復元することはできません）、タスク ID、差し引いたクレジット数、対象のクレジット期間、日時、CLI のバージョン、OS、プロセッサーアーキテクチャ、そして同じ実行が二重に課金されるのを防ぐための技術的な識別子です。クレジットの残高と現在のクレジット期間は、サブスクリプションとともに保存します。投入時の確認では記録を残しません。

### ウェイトリスト [#waitlist]

ウェイトリストのフォームは Tally がホストしています。フォームではメールアドレスの入力をお願いしており、任意で、お使いのコーディングエージェントと、CodeDAG で何をしたいかもお聞きしています。また、どの言語のページから来たか、どのリンクからフォームを開いたかも記録されます。ご回答は Tally に保存されます。メールアドレスは、ベータ版へのご招待と正式リリースのお知らせにのみ使います。

### サーバーログ [#logs]

当社のホスティング事業者は、codedag.com と app.codedag.com への各リクエストについて、日時、リクエスト先のアドレス、応答ステータス、IP アドレス、ユーザーエージェント（CLI の場合はそのバージョンを含みます）などの基本的な情報を記録します。当社のサーバーはエラーも記録します。これらのログは、本サービスの運営、問題の調査、不正利用の防止に使います。リクエストの内容は記録しないため、ワークフローファイルがログに残ることはありません。

### メールとフィードバック [#communications]

お客様から当社にメールをいただいた場合、ご返信と記録のため、メールアドレス、本文、添付ファイルを含むやり取りを保存します。当社の公開 GitHub リポジトリで作成された Issue は誰でも閲覧でき、GitHub の規約に従って取り扱われます。

## 収集しないデータ [#not-collected]

- **リポジトリ内のコード：** お客様のリポジトリのソースコードは収集しません。唯一の例外はワークフローファイルで、前述のとおり、プロンプトやお客様が書き込んだコードを含めて、課金のリクエストとともに送信されます。タスクで機密情報が必要な場合は、ローカルのファイルに置き、どのファイルを読むかをプロンプトでエージェントに指示してください。そうすれば、アップロードされるのはファイルのパスだけです。
- **実行ログとエージェントのセッション：** タスクのログ、エージェントのセッション内容と出力は、お客様のコンピューターに残ります。
- **製品の利用状況の分析：** CLI と Web コンソールには、利用状況の分析やテレメトリーの機能は一切ありません。CLI が当社のサーバーに接続するのは、ログイン、アカウント状態の確認、クレジットの処理のときだけです。
- **エージェントの通信：** Claude Code と Codex は、お客様のコンピューターから直接、各モデル提供元にコードとコンテキストを送信し、その取り扱いには各提供元の規約が適用されます。この通信は CodeDAG のサーバーを経由しません。

## アクセス解析（外部送信） [#analytics]

codedag.com では、サイトの利用状況を把握するため Vercel Web Analytics を利用しています。Cookie は使わず、お客様の端末に識別子を保存することもありません。お客様がサイトを閲覧すると、その閲覧に関する情報が次のとおり外部に送信されます。

- **送信先：** Vercel Inc.（当社の委託を受けてデータを処理します）
- **送信される情報：** 閲覧したページのアドレス（クエリパラメーターはフィルター処理済み）、参照元のページ、OS・ブラウザ・デバイスの種類とそれぞれのバージョン、IP アドレスから推定したおおよその位置情報（国、地域、都市）、日時。ウェイトリストのボタンや、ドキュメントと料金ページへの一部のリンクをクリックした場合は、イベント名とそのリンクのページ内の位置（例：`home-hero`）もあわせて送信されます。個人を特定できる情報は含みません。
- **利用目的：** どのページが閲覧され、どのリンクが使われているかを集計して把握し、サイトの改善に役立てるため
- **訪問者の数え方：** Vercel は、リクエストから生成したハッシュ値で訪問者を数えます。このハッシュ値は毎日リセットされるため、日をまたいで、または他のサイトをまたいでお客様が識別されることはありません。Vercel は、記録するデータが個人や IP アドレスと結び付かないとしています。当社は、この統計データを他の誰とも共有しません。

## Cookie とローカルストレージ [#cookies]

codedag.com は Cookie を設定しません。ライトテーマ・ダークテーマなどの表示設定はブラウザのローカルストレージに保存され、お客様の端末から外に出ることはありません。app.codedag.com が使う Cookie は、ログイン状態を保つために必要なものだけです。広告や分析のための Cookie は使用しません。Stripe の決済ページとカスタマーポータル、Tally のフォームは各事業者が運営しており、それぞれのポリシーに基づいて独自の Cookie を使うことがあります。

## データの利用目的 [#use]

当社は、個人データを次の目的で利用します。

- 本サービスの提供（ログイン、アカウント、クレジット、サブスクリプション）
- 支払いの処理、二重課金の防止、Stripe との課金記録の照合
- メールやご請求（返金やデータに関するご請求を含みます）への対応
- ウェイトリストに登録された方へのベータ版のご招待と正式リリースのお知らせ
- 本サービスの安全の確保、エラーや不正利用の調査
- 税務、会計などの法的義務の履行

法令上、処理の法的根拠を示す必要がある場合、アカウント、利用量、支払いのデータはお客様との契約の履行のために、ログと Web サイトの統計は本サービスの運営・保護とサイトの改善という当社の正当な利益に基づいて、保存が義務付けられた記録は法的義務の履行のために、ウェイトリストのメールアドレスはお客様の同意に基づいて処理します。同意はいつでも撤回できます。

当社は、個人データを販売せず、広告のために共有せず、お客様のワークフローファイル、プロンプト、コードを AI モデルの学習に使うこともありません。

## 業務委託先 [#providers]

当社が個人データを共有するのは、本サービスの運営を支援する事業者だけで、共有するのも各事業者に必要な範囲に限ります。

| 事業者 | 委託している業務 |
|---|---|
| Vercel | codedag.com と app.codedag.com のホスティング、Web サイトのアクセス解析、サーバーログ |
| マネージドデータベース事業者 | アカウント、サブスクリプション、課金記録を保存するデータベースのホスティング |
| Google | Google アカウントでのログイン |
| Stripe | 支払い、サブスクリプション、請求書 |
| Tally | ウェイトリストのフォーム |
| 法人向けメール事業者 | 当社のメールボックスのホスティング |

各事業者は、それぞれの規約とプライバシーポリシーに従ってデータを取り扱います。また、法令で求められる場合や、ユーザーまたは本サービスの権利と安全を守るために必要な場合には、個人データを開示することがあります。Zillion AI が合併、買収、資産の売却の当事者となった場合、個人データはその取引の一部として移転されることがあり、移転後も本ポリシーが引き続き適用されます。

## 国外への移転 [#transfers]

Zillion AI は米国に所在し、当社の委託先は、米国およびその事業を行うその他の国でデータを処理します。お客様が本サービスを利用すると、お客様のデータはこれらの国に移転され、そこで処理されます。これらの国のデータ保護の制度は、お客様がお住まいの国と異なる場合があります。

## 保存期間 [#retention]

- **アカウント、サブスクリプション、課金の記録：** アカウントが存続している間保存します。アカウントの削除後は、会計、税務、その他の法的義務で求められる期間に限り、課金記録を保存します。
- **ワークフローファイルの内容とパス：** 保存しません。クレジットの計算が終わり次第破棄します。
- **サーバーログ：** 最長 30 日間保存した後、削除します。セキュリティ上の事案や不正利用の調査、または法的義務の履行に必要な場合は、該当する部分をより長く保存することがあります。
- **Web サイトのアクセス解析：** 匿名の統計データとしてのみ保存し、日ごとの訪問者のハッシュ値は破棄されます。
- **ウェイトリストの登録内容：** ご招待と正式リリースのお知らせに必要がなくなるまで、またはお客様から削除のご依頼があるまで保存します。
- **メール：** ご依頼への対応と記録に必要な期間保存します。

## お客様の権利 [#rights]

お客様は、当社に次のことを求めることができます。

- 当社が保有するお客様の個人データの写しの提供（持ち運び可能な形式での提供を含みます）
- 不正確なデータの訂正
- アカウントと個人データの削除、またはウェイトリストからの削除
- 特定の処理の制限または処理への異議、およびお客様が与えた同意の撤回

欧州経済領域、英国、カリフォルニア州、日本など、お住まいの地域によっては、これらの権利が法令で認められている場合があります。アカウントがお客様のものであることを確認するため、ご請求は CodeDAG アカウントのメールアドレスから <Email user="privacy" /> までお送りください。これらのご請求はメールで受け付けており、Web コンソールにはまだセルフサービスの機能がありません。アカウントの削除をご希望で、サブスクリプションが有効な場合は、更新されないよう先にサブスクリプションを解約してください。保存が義務付けられた課金記録は、前述のとおり保存します。

これらの権利を行使したことを理由に、お客様を不利に扱うことはありません。お住まいの地域のデータ保護当局に苦情を申し立てることもできます。

## セキュリティ [#security]

当社のサーバーとの通信は HTTPS で暗号化されており、当社が保存するのは本ポリシーに記載したデータだけです。ただし、完全に安全な送信方法や保存方法はありません。お客様の個人データに影響する漏えいが発生した場合は、法令に従ってお知らせします。

## 子どもの個人データ [#children]

本サービスは 18 歳以上の方を対象としています（[利用規約](/ja/terms#accounts)を参照）。当社が子どもの個人データを故意に収集することはありません。子どもが当社に個人データを提供したと思われる場合はご連絡ください。当該データを削除します。

## 本ポリシーの変更 [#changes]

当社は本ポリシーを更新することがあります。新しい版は、施行日を更新したうえでこのページに掲載します。お客様のデータの取り扱いに重大な影響を及ぼす変更の場合は、変更の効力が生じる前に、メールまたは Web コンソールでもお知らせします。

本ポリシーやお客様のデータに関するご質問は、<Email user="privacy" /> までご連絡ください。
