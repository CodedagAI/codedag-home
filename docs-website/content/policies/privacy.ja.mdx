本プライバシーポリシーは、お客様が CodeDAG を利用する際に、Zillion AI LLC（以下「Zillion AI」または「当社」）が個人データをどのように収集、利用、共有するかを説明するものです。CodeDAG には、コマンドラインツール（以下「CLI」）、Web コンソール app.codedag.com、Web サイト codedag.com（以下総称して「本サービス」）が含まれます。これらのデータの管理者は Zillion AI です。本ポリシーは、当社の[利用規約](/ja/terms)の一部を構成します。

CodeDAG はお客様のコンピューター上で動作し、お客様のコード、実行ログ、エージェントのセッションはそのコンピューターに残ります。当社が収集するのは、お客様のアカウントの運用、クレジットの計算、支払いの処理に必要なデータだけです。

## 収集するデータ [#what-we-collect]

### お客様から提供されるデータ [#you-provide]

- **アカウント情報：** ログインには Google アカウントを使い、当社はお客様の氏名、メールアドレス、プロフィール画像、Google アカウント ID を受け取ります。CodeDAG が招待制の間は、招待リストに載っているメールアドレスでのみアカウントを作成できます。招待リストは、ウェイトリストと当社が個別に行う招待をもとに作成します。
- **支払い情報：** 支払いページでは、以前に選択された内容、または IP アドレスから推定したおおよその所在地をもとに、お客様の国などの請求先地域と、税務上必要な場合は郵便番号をあらかじめ入力します。お客様はこれを変更できます。その地域で有料プランをご利用いただける場合は、お申し込みに至らなくても、税額の計算のために請求先地域を Stripe に送信します。カード情報は、当社の決済代行事業者である Stripe の支払いフォームに入力していただきます。当社がカード番号の全体を受け取ることはありません。お申し込みの際は、更新条件に同意された日時、表示された条件の文言、価格を記録します。
- **ウェイトリスト：** ウェイトリストに登録すると、当社のフォーム提供事業者が、メールアドレス、いくつかの任意の質問へのご回答、フォームにたどり着く前に見ていたページを収集します。
- **お問い合わせ：** 当社にご連絡いただいた場合は、メッセージ、メールアドレス、添付ファイルを保存します。当社の公開 GitHub リポジトリで作成された issue は誰でも閲覧でき、GitHub の規約に基づいて取り扱われます。

### 本サービスの利用時に収集するデータ [#usage]

- **ワークフローファイル：** クレジットを計算して差し引くため、CLI は、お客様が実行するワークフローファイルを、プロンプトとファイル内に書かれたコードを含めて当社に送信します。あわせて、実行するタスクと、CLI のバージョンや OS などの技術情報も送信します。当社はこのファイルをクレジットの計算とチェックサムの作成にだけ使い、その後ファイルの内容を破棄します。内容は当社のデータベースにもログにも保存しません。CLI がいつ何を送信するかは、[送信されるデータの範囲](/ja/docs/account/login-and-account#data-boundary)で詳しく説明しています。
- **利用状況とクレジットの記録：** 実行が始まったワークフローごとに、日時、タスク、差し引いたクレジット、ワークフローファイルのチェックサムなどの記録を保存します。チェックサムからファイルを復元することはできません。また、クレジットの残高と、[返金ポリシー](/ja/refund#credits)に基づくクレジットの返還など、当社がクレジットに加えた変更も保存します。
- **端末とログの情報：** 当社のサーバーと委託先は、本サービスへのリクエストに関する技術情報を記録します。たとえば、IP アドレス、ブラウザや CLI のバージョン、OS、リクエストの日時、発生したエラーなどです。
- **Web サイトのアクセス解析：** codedag.com では、Cookie を使わないアクセス解析サービスでアクセスを集計しています。閲覧したページ、参照元のページ、ブラウザと端末の種類、おおよその所在地、クリックしたリンクなどを記録しますが、日をまたいで、または他の Web サイトをまたいでお客様を識別することはできません。

リポジトリ内のコード、実行ログ、エージェントのセッションは当社に送信されません。Claude Code や Codex などのコーディングエージェントは、お客様のコンピューターから直接、各モデル提供元にコードとコンテキストを送信し、それらは各提供元の規約に基づいて取り扱われます。この通信は当社を経由しません。CLI と Web コンソールには、製品の利用状況を分析する機能はありません。

### 第三者から受け取るデータ [#third-parties]

Stripe からは、サブスクリプションと支払いの記録を受け取ります。たとえば、プラン、請求日と金額、請求先住所、カードの発行国などです。また、当社の決済ページで動作する Stripe の決済ソフトウェアは、不正防止のため、お客様の端末に関する情報やページ上での操作を収集することがあります。Stripe はこれらの情報を同社の[プライバシーポリシー](https://stripe.com/privacy)に基づいて取り扱います。

## データの利用目的 [#use]

当社は、個人データを次の目的で利用します。

- 本サービスの提供（ログイン、アカウント、クレジット、サブスクリプションを含みます）。CodeDAG が招待制の間は、アカウントを作成できる人と、そのアカウントに付与する無料クレジットの決定を含みます
- 支払いの処理、税金の計算、お客様の地域で有料プランを利用できるかの確認、不正利用と二重課金の防止
- アカウント、クレジット、サブスクリプションに関するお知らせの送信と、ご請求への対応
- ウェイトリストに登録された方へのベータ版のご招待と正式リリースのお知らせ、および CodeDAG の使い方に関するご要望の把握
- 本サービスの安全の確保、エラーや不正利用の調査
- Web サイトの利用状況の集計と、それに基づく改善
- 税務、会計、消費者保護などの法的義務の履行

当社は個人データを販売せず、広告のために共有することもありません。また、お客様のワークフローファイル、プロンプト、コードを AI モデルの学習に使うこともありません。

## 処理の法的根拠 [#legal-bases]

当社は、次の法的根拠に基づいて個人データを処理します。

- **契約：** お客様が申し込んだ本サービス（アカウント、クレジット、支払いを含みます）の提供
- **正当な利益：** 本サービスの安全の確保と問題の調査、不正の防止、ベータ期間中の登録の制限、Web サイトの改善
- **同意：** ウェイトリストへの登録後にお送りする、ベータ版と正式リリースに関するメール。同意はいつでも撤回できます
- **法的義務：** 税務、会計、消費者保護の法令が求める記録の保存

## データの共有 [#sharing]

当社が個人データを共有するのは、次の場合に限られます。

- **委託先：** 本サービスの運営のために、ホスティングとデータベース、ログイン、決済処理と税金の計算、エラーの追跡、ログと稼働状況の監視、Web サイトのアクセス解析、フォーム、メール、コードのホスティングと自動化などの分野で事業者を利用しています。各事業者が受け取るのは、その業務に必要なデータだけです。決済代行事業者など一部の事業者は、自社のプライバシーポリシーに基づいてもデータを取り扱います。
- **法令上の要請と安全：** 法令で求められる場合、またはユーザーや本サービスの権利と安全を守るために必要な場合は、個人データを開示することがあります。
- **事業の譲渡：** Zillion AI が合併、買収、資産の売却に関わる場合、個人データはその取引の一部として移転されることがあり、移転後も本ポリシーが適用されます。

## Cookie と類似の技術 [#cookies]

codedag.com は Cookie を使いません。ライトテーマ・ダークテーマなどの表示設定はブラウザのローカルストレージに保存され、お客様の端末から外に出ることはありません。app.codedag.com が使う Cookie は、ログイン状態を保つためのものや、選択した言語を記憶するためのものなど、動作に必要なものだけです。広告のための Cookie は使用しません。支払いフォーム、請求ポータル、ウェイトリストのフォームは当社の決済代行事業者とフォーム提供事業者が運営しており、独自の Cookie を使うことがあります。

当社は他の Web サイトをまたいでお客様を追跡しないため、「Do Not Track」シグナルに応じて取り扱いを変えることはありません。本ポリシーに記載したアクセス解析と委託先を除き、当社のサイトでお客様の行動に関する情報を第三者が収集することは認めていません。

## 国外への移転 [#transfers]

Zillion AI は米国に所在し、当社の委託先は、米国およびその事業を行うその他の国でデータを処理します。当社のチームが他の国からデータにアクセスすることもあります。こうした移転に法令上の保護措置が必要な場合は、委託先の契約上の約束により、同等の水準の保護を確保します。たとえば欧州経済領域や英国からのデータについては、欧州委員会が承認した標準契約条項や、英国でこれに相当するものを用います。写しをご希望の場合は、当社までご連絡ください。

## 保存期間 [#retention]

当社は、本ポリシーに記載した目的に必要な期間に限って個人データを保存し、その後は削除または匿名化します。

- **アカウント、クレジット、サブスクリプション、課金の記録：** アカウントが存続している間保存します。アカウントの削除後は、税務、会計、その他の法的義務で求められる期間に限り、サブスクリプションと課金の記録を保存します。
- **ワークフローファイルの内容：** 保存しません。クレジットの計算が終わり次第破棄します。
- **ログとエラーレポート：** 本サービスの運営、問題の調査、安全の確保に必要な短い期間だけ保存します。セキュリティ上の事案や不正利用の調査、または法的義務の履行に必要な場合は、該当する記録をより長く保存することがあります。
- **ウェイトリストと招待リストの登録内容：** ご招待と正式リリースのお知らせに必要がなくなるまで、またはお客様から削除のご依頼があるまで保存します。
- **メール：** ご依頼への対応と記録に必要な期間保存します。

## お客様の権利 [#rights]

欧州経済領域、英国、カリフォルニア州、日本など、お住まいの地域によっては、次の権利が認められている場合があります。

- 当社が保有するお客様の個人データへの**アクセス**と、持ち運び可能な形式での写しの取得
- 不正確なデータの**訂正**
- アカウントと個人データの**削除**、またはウェイトリストからの削除
- 特定の処理への**異議**または処理の**制限**
- お客様が与えた同意の**撤回**

アカウントがお客様のものであることを確認するため、ご請求は CodeDAG アカウントのメールアドレスから <Email user="privacy" /> までお送りください。アカウントの削除をご希望で、サブスクリプションが有効な場合は、更新されないよう先にサブスクリプションを解約してください。これらの権利を行使したことを理由に、お客様を不利に扱うことはありません。当社のデータの取扱いについてのご懸念や苦情も、同じアドレスまでお送りください。ご請求と苦情には 20 営業日以内に回答します。回答にご満足いただけない場合は、お住まいの地域のデータ保護当局に苦情を申し立てることもできます。

## セキュリティ [#security]

当社が保存するのは本ポリシーに記載したデータだけです。当社のサーバーとの通信は HTTPS で暗号化し、個人データにアクセスできる者を限定しています。ただし、完全に安全な送信方法や保存方法はありません。お客様の個人データに影響する漏えいが発生した場合は、法令に従ってお知らせします。

## 子どもの個人データ [#children]

本サービスは 18 歳以上の方を対象としています（[利用規約](/ja/terms#accounts)を参照）。当社が子どもの個人データを故意に収集することはありません。子どもが当社に個人データを提供したと思われる場合はご連絡ください。当該データを削除します。

## 本ポリシーの変更 [#changes]

当社は本ポリシーを更新することがあります。新しい版は、施行日を更新したうえでこのページに掲載します。お客様のデータの取り扱いに重大な影響を及ぼす変更の場合は、変更の効力が生じる前に、メールまたは Web コンソールでもお知らせします。
