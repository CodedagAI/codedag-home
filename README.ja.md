# CodeDAG

[English](./README.md) · [简体中文](./README.zh.md) · 日本語

CodeDAG は、コーディングエージェントのためのオーケストレーションエンジンです。開発タスクとその依存関係を 1 つのワークフローファイルに書くと、手元のマシンで依存関係に従ってスケジュールします。各タスクは新しいエージェントセッションと専用のブランチで進み、結果は統合ブランチに自動でマージされます。メインブランチにマージするかどうかは自分で決められます。

**詳しくは[ドキュメント](https://codedag.com/ja/docs)をご覧ください。**

## インストール

現在はプライベートベータのウェイトリストを受け付けている段階のため、CodeDAG はまだインストールできません。インストール方法は、プライベートベータの開始後にここに追加します。

[ウェイトリストに登録](https://codedag.com/ja/waitlist?source=github-readme)して、招待をお待ちください。招待はメールで順次お送りします。招待された方は、ベータ期間中に無料クレジットを利用できます。

## フィードバック

CodeDAG の問題の報告や機能の提案は、[Issue を作成](https://github.com/CodedagAI/codedag-home/issues/new/choose)してお寄せください。問題を報告する前に、[トラブルシューティング](https://codedag.com/ja/docs/troubleshooting/troubleshooting)をご確認ください。答えが見つかるかもしれません。ドキュメントや codedag.com ウェブサイトの問題もここで報告できます。

Issue は公開されます。API キー、トークン、非公開のコードは貼り付けないでください。ログやワークフローファイルを共有する前に、これらが含まれていないか確認してください。公開の場で話せない問題やその他のお問い合わせは、hi@codedag.com までメールでご連絡ください。セキュリティ上の脆弱性の報告については [SECURITY.md](./SECURITY.md) をご覧ください。

## プライバシー

CodeDAG はお客様のコンピューター上で動作します。リポジトリ内のコード、実行ログ、エージェントのセッションは、そのコンピューターに残ります。ワークフローの投入時と実行開始時に、CLI はクレジットを計算するため、プロンプトを含むワークフローファイルを当社に送信します。当社は計算後にファイルを破棄し、チェックサムだけを保持します。Claude Code と Codex は、お客様のコンピューターから直接、各モデル提供元と通信します。この通信は当社を経由しません。詳しくは[プライバシーポリシー](https://codedag.com/ja/privacy)をご覧ください。
